Synchronous FIFO Architecture & Principles

1. Circular Pointer Arithmetic

A FIFO does not physically shift all data registers like a shift register. Instead, it utilizes two modular pointers: Write Pointer (w_ptr) for push and Read Pointer (r_ptr) for pop.

w_ptr <= (w_ptr + 1'b1) % DEPTH;
2. Full vs Empty Disambiguation

When w_ptr == r_ptr, the buffer is either completely full or completely empty. Tracking an auxiliary occupancy counter (count) eliminates ambiguity.

empty = (count == 0); full = (count == DEPTH);
3. Overflow & Underflow Protection

Writing into a full FIFO corrupts unread data (overflow), while reading from an empty buffer pulls garbage logic levels (underflow). Hardware guards ignore invalid requests.

if (wr_en && full) overflow <= 1'b1;
4. Simultaneous Push & Pop

In high-throughput FPGA pipelines, reading and writing can occur on the exact same clock edge. Both pointers advance synchronously while the occupancy counter remains stable.

mem[w_ptr] <= din; dout <= mem[r_ptr];
