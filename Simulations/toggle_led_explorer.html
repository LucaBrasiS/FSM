Circuit Theory & Hardware Principles

1. Why Do We Count? (Clock Division)

FPGA system clocks run at 50 MHz or 100 MHz (millions of cycles/sec). Directly driving an LED would toggle it imperceptibly fast, making it appear constantly dim. Counting divides the high frequency down to human eye limits (e.g. 1 Hz - 2 Hz).

f_out = f_clk / (2 * HALF_PERIOD)
2. Counter Step (cnt Logic)

On every rising clock edge (posedge clk), if synchronous reset is low, the counter increments sequentially by one.

cnt <= cnt + 1'b1;
3. Toggle Trigger (Inversion)

When the counter reaches the threshold (cnt == HALF_PERIOD - 1), it resets to zero and toggles the T-Flip-Flop output state (0 ➔ 1 or 1 ➔ 0).

cnt <= 0; led <= ~led;
4. Register Width ($clog2)

Verilog's built-in $clog2(HALF_PERIOD) function calculates the minimal number of bits needed for the counter without hardcoding magic numbers.

reg [$clog2(HALF_PERIOD)-1:0] cnt;
